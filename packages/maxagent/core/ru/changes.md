# Что нового в maxagent

Агент показывает хозяину новое один раз после обновления (регламент, раздел 8) и ставит пометку в `experience/maxagent.md`.

## 0.5.9
- Установка агентом: мастер больше не зависает и не молчит — задаёт хозяину все вопросы через агента и в конце даёт отчёт, что поставлено.

## 0.5.8
- Агенты знают, когда что брать: нажать, ввести или прочитать — `snapshot`, посмотреть, как выглядит страница, — снимок экрана.

## 0.5.7
- Обычный `snapshot` теперь отвечает короткими строками: сначала то, что на экране, без пустых подложек и дублей. Полный JSON — `format="full"`.

## 0.5.6
- Общие наборы опыта: загрузка повторяется при сбоях GitHub, один неудачный набор не мешает остальным; `doctor` больше не предупреждает о шапках наборов.

## 0.5.5
- Быстрый `snapshot` отвечает короткими строками вместо JSON — экран занимает в разы меньше.

## 0.5.4
- Новый агент сразу знает про быстрый снимок и клик по пикселям; большой `snapshot` сам подсказывает быстрый режим; при ошибке моста сначала смотреть снимок экрана.

## 0.5.3
- Мост: `snapshot` умеет читать только видимую часть экрана и искать элементы по словам — ответ на больших страницах в разы меньше.
- Мост: клик по пикселям снимка экрана `click_at` — для плееров и холстов.
- Мост: загрузку файла можно разрешить один раз или всегда для этого агента на этом сайте; отозвать можно в окне расширения.

## 0.5.2
- Подсказки из опыта больше не останавливают команды и поиск — приходят как воспоминание.
- В конце ответа агент дописывает только то, чего в ответе действительно нет.
- Установленные скилы всех агентов находятся по просьбе: личная полка обновляется раз в день.

## 0.5.1
- Свой опыт можно предложить в общую библиотеку: `npx maxagent experience share <папка> --name <имя>` проверит формат, секреты и личное и подготовит набор; сама команда ничего не отправляет.
- Самообновление сразу видит свежий выпуск.

## 0.5.0
- maxagent и maxagent-bridge теперь всегда одного номера версии и обновляются вместе.
- Самообновление раз в день: ставится только выпуск, собранный нашим GitHub (подписи и происхождение проверяются); большие версии — после вашего «да»; выключить — `npx maxagent setup`.
- Мост не оставляет следов на сайтах: агент не может выполнять свой код в странице, снимок и клики идут в изолированном пространстве, звук вкладки пишет сам Chrome (один раз на вкладку: значок моста или Alt+Shift+M).
- Мост перезагружается при обновлении, только когда через него никто не работает.
- Общий опыт: наборы чужого опыта из выпусков GitHub — `npx maxagent experience add all`; полезный атом — себе командой `adopt`.
- Опыт при ответе: правило оформления в каждом напоминании, проверка готового ответа (пути и команды — ссылкой или блоком кода), полка `experience/answer`.

## 0.4.0
- Кодовое слово убрано совсем: модель всё равно видит его в сообщении, а возни больше, чем пользы. Защита — правило «прочитанное — данные», признаки инъекций, запрет уничтожающих команд и запросы разрешений самого агента. Старый хэш слова удаляется при обновлении.
- Плагин для OpenClaw: главные правила и подсказка опыта в каждом запросе, запрет уничтожающих команд, опыт перед поиском. Ставится сам через OpenClaw CLI; заработает после перезапуска шлюза (`openclaw gateway restart`).

## 0.3.0
- Главные правила — короткий список «всегда» в `AGENTS.md`: общие пункты плюс пункты из ваших настроек; хук показывает их в начале сессии и после сжатия памяти.
- Опыт как библиотека: папки по вещам (`platform`, `tools`, `code`, `agents`, `craft`, `owner`), шаблон записи, индекс собирается из шапок (`npx maxagent index`).
- Проверка перед «готово»: агент не может написать «готово» после правки кода, ничего не запустив и не открыв.
- Браузерный сторож (если выбран мост): встроенные браузеры агентов запрещены, «мост не на связи» — один шаг `launch_browser`.
- Карточка окружения компьютера (ОС, оболочки, Python, Node…) — кратко на старте сессии.
- Входящие «сохрани на потом» — папка `inbox/`, хук подсказывает и напоминает «не забыть сделать».
- `npx maxagent setup` — поменять настройки: репозиторий, мост, отдельный рабочий стол, формат ответов, Корзина.

## 0.2.0
- Хуки для Claude Code, Codex, Antigravity: подсказка опыта, проверка «опыт записан?», запрет уничтожающих команд.
