# craft/ — База направлений

Папка на направление (`craft/youtube/`, `craft/design/`…): ремесло, общее для всех проектов этого направления. Конкретный канал или клиент — в `projects/`.

Новая запись — атомами по спецификации `../_spec.md` (заготовка — `../_template.md`), затем `lint` (см. `../../experience.md`). Этот README в индекс не попадает.
