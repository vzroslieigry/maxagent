### Нужно сохранить пароль, ключ или токен
- когда: сохрани ключ · запиши пароль · токен в конфиг · API key в файл · добавить .env
- вещь: секреты · опыт · репозиторий · .gitignore
1. Само значение — никогда в опыт, проекты, логи, коммиты и ответы. Записывать только **где лежит**: «ключ — в менеджере паролей», «токен — в переменной окружения `<ИМЯ>`».
2. Программе нужен ключ — переменная окружения или локальный файл, который внесён в `.gitignore` до первого коммита.
3. Перед коммитом посмотреть `git diff --cached` на похожее на ключ.
- проверка: `node ~/.maxagent/tools/experience-engine.js lint <файл>` не ругается на секрет
- ловушка: не вводить пароли и платёжные данные за хозяина — вход и оплату делает он сам
- источник: опыт maxagent, 2026

### Секрет уже попал в файл или коммит
- когда: ключ попал в коммит · токен в репозитории · пароль в логе · случайно закоммитил ключ
- вещь: секреты · git · утечка
1. Сразу сказать хозяину: какой секрет и где он виден.
2. Убрать значение из файла; если коммит уже отправлен — секрет считать раскрытым: хозяин меняет его у сервиса.
3. Переписывать историю git — только по слову хозяина.
- ловушка: удаление из следующего коммита не убирает секрет из истории
- источник: опыт maxagent, 2026
