# Входящие — несортированное «сохрани на потом»

Хозяин говорит «сохрани это», «на потом», «запомни», «кинь в <проект>» — агент кладёт сюда **как есть, без разбора и без вопросов «куда»**. Чтобы ничего не терялось «где попало».

- Назван проект или речь явно о текущем проекте → `projects/<проект>/inbox/`; иначе — сюда. Для будущего проекта (папки ещё нет) — сюда, со строкой `Проект: <имя>`.
- Одна вещь — один файл `ГГГГ-ММ-ДД-<коротко-латиницей>.md`: что дал хозяин — **дословно** (текст, ссылка; картинка или файл — копией рядом с тем же именем), строка «Откуда:» (чат, страница, файл) и «Зачем:», если сказано. Не переписывать, не сокращать, не сортировать.
- **Скрин или скопированные файлы** (хозяин кладёт их в буфер обмена) — на Windows скриптом: картинка станет PNG, файлы — копиями, текст — `.md`:
  ```
  powershell -NoProfile -STA -File "{{TOOLS}}/save-clip.ps1" -Dir inbox -Name ГГГГ-ММ-ДД-<коротко>
  ```
  Рядом — `.md` с «Откуда:» / «Зачем:».
- **Ссылка** — адрес дословно и что о ней сказал хозяин; страницу не открывать и не пересказывать (разбор — потом). **Мысль, идея** — дословно его словами.
- Строка **`Вид:`** — `будущая задача` / `будущий проект` / `на потом для проекта` / `не забыть сделать`. Пункты «не забыть сделать» хук показывает в начале каждой сессии.
- Если включён репозиторий — сразу сохранить и отправить. Ответ хозяину — одна строка со ссылкой на файл.
- «Найди, что я сохранял про …» — искать по всем входящим сразу (`inbox/` и `projects/*/inbox/`).
- **Разбор — только по команде хозяина** («разбери входящие»): каждая вещь — в опыт, в проект или в Корзину по его слову; разобранное отсюда убрать.

Образец файла:
```
# <коротко, о чём>
Вид: не забыть сделать
Проект: <имя, если есть>
Откуда: чат, ГГГГ-ММ-ДД
Зачем: <если сказано>

<дословно, что дал хозяин>
```
