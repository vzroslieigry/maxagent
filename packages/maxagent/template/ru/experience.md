# Индекс опыта

Опыт обычно всплывает сам: хук maxagent показывает подходящий атом на сообщение, перед командой и после ошибки. Не всплыл — найти:

```
node ~/.maxagent/tools/experience-engine.js find "<слова задачи>"
```

или просмотреть таблицу ниже и прочитать подходящие файлы. Запись не доказывает, что подключение или программа работают сейчас: изменяемое проверяй.

**Как устроено.** Одна вещь — один файл `experience/<вид>/<вещь>.md`, по вещи, а не по случаю. Виды: `platform/` — система и окружение; `tools/` — программы и сервисы; `code/` — языки и библиотеки; `agents/` — сами агенты и их хуки; `craft/<направление>/` — ремесло, общее для всех проектов направления; `owner/` — как хозяин любит работать. Проектное — в `projects/<проект>/`, не сюда. В файле — атомы `###`: одна задача, ловушка или правило, до 900 знаков.

**Новая запись** — по спецификации `experience/_spec.md` и заготовке `experience/_template.md`, затем проверка:

```
node ~/.maxagent/tools/experience-engine.js lint experience/<вид>/<вещь>.md
```

Таблицу ниже руками не править — она собирается из шапок (`title`, `task`, `aliases`):

```
node "{{TOOLS}}/experience-index.js"
```
