### Check the result before saying "done"
- когда: done · check the result · finished · report back · everything works check
- вещь: check · report · result
1. Look at the result itself, not at signs of it: a frame — open and look, sound — listen, a file — open it, a command — run it, a page — reload it.
2. Make sure the program actually got the change: a file on disk does not prove it.
3. In the report separate programmatic checks (tests, logs, exit code) from what you saw with your own eyes.
4. Not checked — say so: "not verified", and why.
- проверка: the report says what exactly was checked and how
- ловушка: tests, logs and a tool's reply do not replace checking the result itself
- источник: maxagent experience, 2026

### The way did not work
- когда: way did not work · repeated command error · task failed · try another way
- вещь: report · next way · check
1. No excuses or apologies: one line on what failed — and the next way.
2. Don't repeat a failed action the same way until the cause is known.
3. After the new way — check the result again.
4. A working way found after an error — write it into experience.
- ловушка: not "almost done" — there is a verified result or there isn't
- источник: maxagent experience, 2026
