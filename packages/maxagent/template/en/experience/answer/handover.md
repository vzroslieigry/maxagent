### Hand a finished file to the owner
- когда: the file is ready · saved the file to · voice-over file · final file · path to the file · file is in the folder
- вещь: answer to the owner · link · path
1. To look at — a clickable link: `[voice.txt](C:/Users/…/voice.txt)`.
2. To pass on (paste into a program, another agent) — the full path in a separate code block.
3. Several files or folders — a list of links, a few words "what it is" each.
4. The answer already went out without links — do not rewrite it: add only the list of links at the end.
- ловушка: not a path as plain text in a sentence — the owner can neither open nor copy it in one click
- источник: maxagent experience, 2026

### Give the owner a command to run
- когда: run this command · run it in the terminal · command to copy · type in the console
- вещь: answer to the owner · code block · command
1. Each command — its own code block; several in a row — one block.
2. No `$` in front, no output inside the block.
- ловушка: not a command inside a sentence or inline backticks — it cannot be copied in one click
- источник: maxagent experience, 2026

### Report what was done
- когда: the work is ready · everything works · result verified · not verified yet · result of the work
- вещь: report · verification
1. What was checked by a program (test, command) — separate from what was seen or heard yourself.
2. Not verified — say "not verified" and why.
3. What is left — briefly at the end.
- ловушка: not "done" without a check — the owner learns about the error from viewers, not from the agent
- источник: maxagent experience, 2026

### Hand over a video publishing pack
- когда: video is ready · video title · video description · tags · thumbnail ready · subtitles ready
- вещь: publishing pack · YouTube · code blocks
1. Each in its own code block: title, thumbnail path, the whole description, tags, `.srt` path, video path.
- ловушка: not one block of text — the owner copies each field into its own box in YouTube Studio
- источник: maxagent experience, 2026
