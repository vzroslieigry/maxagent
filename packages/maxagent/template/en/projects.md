# Project registry

Before a project task, check this registry and the project card `projects/<name>/README.md`. When the task is done, update the stage status and the row here.

- Projects live permanently and grow in stages.
- Statuses belong to stages and tasks, not projects: `[▶] in progress`, `[⏸] paused / blocked`, `[✓] done`, `[ ] planned`.
- Tasks and incidents are cards in `projects/<name>/tasks/` (5 blocks: symptom, diagnosis, root cause, what was done, how to check).
- Transferable knowledge goes to `experience/`, not into the project.
