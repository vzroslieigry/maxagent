# maxagent

[English](README.md)

Регламент работы для любого ИИ-агента на вашем компьютере — Claude Code, Codex, Antigravity, OpenClaw. Главное в нём — **опыт**.

Агенты раз за разом решают одну и ту же задачу с нуля: ищут, пробуют, ошибаются и снова находят способ. maxagent даёт им всем **одну рабочую папку**: базу **опыта** из коротких проверенных рецептов («атомов»), проекты, которые помнят, где остановилась работа, и одни правила перед каждой задачей. Хуки сами показывают нужный атом — на ваше сообщение, перед командой, после ошибки, — и агент делает известным способом, а не наугад.

| Пакет | Что это |
|---|---|
| [`maxagent`](packages/maxagent) | правила, рабочая папка, движок опыта, хуки для каждого агента, мастер установки |
| [`maxagent-bridge`](packages/maxagent-bridge) | «руки» агента: MCP-сервер, который работает в **вашем** Chrome (ваш профиль, ваши входы) через небольшое расширение — без открытого порта, с разрешением на каждого агента, списком запрещённых сайтов, журналом действий и кнопкой «стоп» |

## Установка

Одной фразой агенту:

> Установи maxagent: выполни `npx maxagent init`. Без терминала он выдаст вопросы — задай их мне, ничего не выбирай за меня и ничего не пропускай, в конце передай мне его отчёт.

Или самому:

```
npx maxagent init
```

Нужен только Node.js 18+. При `npm install` ничего не запускается (npm v12 не выполняет скрипты установки, и они нам не нужны): всё тяжёлое качает мастер — и только после вашего «да».

## Что ставит мастер

1. **Рабочая папка** (по умолчанию `~/maxagent`): `AGENTS.md`, `experience/`, `projects/`, `sync.md`, `inbox/`. Эти файлы ваши. Обновление трогает в `AGENTS.md` только блоки между метками (главные правила, настройки) и добавляет файлы шаблона, новые в этой версии; в 0.6.0 оно один раз заменяет строку «прочитай регламент на старте» справкой (копия — `AGENTS.md.maxagent-backup`). На старте агент читает только `AGENTS.md`, опыт всплывает атомами под задачу. По желанию — закрытый Git-репозиторий для синхронизации.
2. **Правила и хуки** для каждого найденного агента (Claude Code, Codex, Antigravity, OpenClaw): короткий блок с метками в общих правилах агента и хуки, которые на каждом ходу показывают опыт. Ваши правила и хуки не трогаются; перед правкой чужого файла — резервная копия.
3. Один вопрос — **«Установить всё / Выборочно / Ничего»** — про дополнения:
   - **Браузерный мост и расширение Chrome** (`npx maxagent bridge`). Расширение пока ставится распакованным: три клика в `chrome://extensions` (Режим разработчика → «Загрузить распакованное» → папка). Мастер ждёт, пока мост выйдет на связь.
   - **Поиск по смыслу** (`npx maxagent vectors`, ~270 МБ): модель `multilingual-e5-small` (зафиксированная ревизия, проверка sha256) и её библиотеки Python в `~/.maxagent/vector`. Нет Python — мастер предложит поставить (на Windows через `winget`, после отдельного «да»); без него поиск только по словам.
   - **Общие наборы опыта** (`npx maxagent experience add all`).
4. Итог: что включено, что пропущено и какой командой включить позже.

| Команда | Что делает |
|---|---|
| `npx maxagent init` | первая настройка |
| `npx maxagent setup` | поменять настройки |
| `npx maxagent doctor` | что установлено и в порядке ли |
| `npx maxagent update` | обновить правила, хуки и блоки у агентов; в рабочей папке — только блоки с метками в `AGENTS.md` и новые файлы шаблона |
| `npx maxagent bridge` · `vectors` | поставить дополнение позже |
| `npx maxagent experience list \| add <набор>\|all \| update \| mute <набор> \| adopt "<id>"` | общий опыт |
| `npx maxagent uninstall` | убрать блоки и хуки у агентов; рабочая папка остаётся |

## Две полки опыта

- **Свой** — `experience/` в рабочей папке. Пишут ваши агенты по ходу работы, по формату `experience/_spec.md`. Свой опыт показывается первым и может остановить команду, про которую известно, что она не сработает.
- **Общий** — `experience/shared/<набор>/`, скачивается из этого репозитория. Только справочник: показывается, только когда своего нет, с порогом выше, не больше одного атома за сообщение, коротко (заголовок и первый шаг) и **никогда** не останавливает команды. Пригодился — `npx maxagent experience adopt "<id>"` копирует атом в свой опыт, общая копия скрывается. Набор мешает — `mute`.

Наборы собираем мы, с готовыми сжатыми векторами (int8, та же модель и ревизия, что у вас), — у вас они не пересчитываются. Набор — один JSON-файл в GitHub Release; `packs/catalog.json` перечисляет их с sha256 и размером. Перед установкой клиент проверяет контрольную сумму, имена файлов и сам текст (скачать-и-выполнить, попытки переписать правила агента, отправка секретов, уничтожающие команды, скрытые символы) и при любой находке не принимает набор целиком. CI делает те же проверки для каждого исходника в `packs/src/`.

## Приватность: что уходит в сеть

maxagent ничего не отправляет о вас. Все запросы — обычные GET публичных файлов:

| Когда | Куда | Зачем |
|---|---|---|
| сам `npx` | `registry.npmjs.org` | скачать пакет |
| раз в сутки в фоне (если `updates` включено) | `registry.npmjs.org/maxagent/latest`, `…/maxagent-bridge/latest` | есть ли новая версия |
| та же проверка | `raw.githubusercontent.com/vzroslieigry/maxagent/main/news.json` | разовые подсказки («расширение в магазине» и т. п.) |
| только после «да» | `raw.githubusercontent.com/…/packs/catalog.json`, GitHub Releases | общие наборы опыта |
| только после «да» | `huggingface.co/Xenova/multilingual-e5-small` (зафиксированная ревизия), PyPI | модель и библиотеки поиска по смыслу |

`updates: false` в `npx maxagent setup` → никаких запросов. У браузерного моста своей сетевой части нет: расширение говорит с локальной программой через Native Messaging Chrome, агенты — с ней через локальный канал.

## Обновления

- Раз в сутки, в фоне, с коротким тайм-аутом; ошибка сети — молча.
- Новая версия — один раз, при старте сессии: `npx maxagent@latest update` и 1–3 строки «что нового». Обновляет агент после вашего «да».
- `autoUpdate: "patch"` — исправления той же линии ставятся сами; всё крупнее ждёт «да».
- Новости из `news.json` показываются один раз на id (`~/.maxagent/state/update-shown.json`).

## Устройство репозитория

```
packages/maxagent          основной пакет
packages/maxagent-bridge   браузерный мост
packs/src/<набор>/         исходники общего опыта (атомы Markdown)
packs/catalog.json         выпущенные наборы: версия, адрес, sha256, размер
news.json                  разовые подсказки установленным копиям
scripts/                   синхронизация и проверки для CI
```

Переводы правил сделаны агентом и носителями языка пока не проверены.
